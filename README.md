EMBERKEEP — defend the last lantern. A complete original arena survival game: move with WASD, aim with the mouse, hold click to fire embers at the shadows; your lantern's light burns what stands inside it. Survive all 10 waves, pick a blessing between waves, and face the Gloom Warden.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is plain static files under `game/`.
